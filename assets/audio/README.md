# Vinheta Salominho

Tema original de abertura do protótipo: Sol maior, 112 BPM, aproximadamente 11,8 segundos.

- `salominho_vinheta_v01.mid`: partitura MIDI editável.
- `src/audio.py`: síntese WAV automática no primeiro início, sem dependências extras.
- Copie o `salominho_vinheta_v01.ogg` de alta qualidade do pacote de áudio para esta pasta se desejar o arranjo estéreo original. O Pygame prioriza o OGG.

A faixa foi desenvolvida para o Salominho; não contém gravações comerciais.
