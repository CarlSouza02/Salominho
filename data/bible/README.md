# Textos bíblicos

A versão 0.1 consulta `bible-api.com` para Gênesis 1:1-5 e mantém cache local. Sem rede, usa apenas uma amostra licenciada de Gênesis 1:1.

Para uma versão offline completa, importar uma tradução com licença aberta para SQLite, incluindo `translation`, `book`, `chapter`, `verse` e `text`, com índice composto.

Fonte candidata: Bíblia Livre (2018), https://ebible.org/Bible/details.php?id=porbr2018, CC BY 4.0. Preservar atribuição e indicar alterações. Conferir separadamente os direitos de imagens e outros materiais.

Não distribuir NVI, ACF ou outras traduções protegidas sem licença adequada.
